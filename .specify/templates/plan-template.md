- **Feature Boundaries**: Identify the affected view, view model, service, and
  repository boundaries. Confirm new dependencies use `FactoryKit` or an
  equally testable injection seam.
- **Apple Platform Standards**: Confirm the feature uses current stable Swift
  and SwiftUI patterns supported by the deployment target, and document any
  deliberate deviation from Apple Human Interface Guidelines or native platform
  conventions.
- **State Ownership**: Name the owner of any shared or UI-observed state and
  describe main-actor or concurrency expectations for each mutation path.
- **Testing**: List the automated tests required for the change. Behavior
  changes MUST include tests, and bug fixes MUST include a regression test.
- **Privacy & Data Handling**: Document persistence, offline/background
  behavior, failure recovery, and any logging or telemetry constraints for user
  data touched by the feature.
- **Verification**: List the lint, build, and test commands plus any manual
  simulator/device validation needed for lifecycle-sensitive behavior,
  accessibility review, and HIG alignment.
